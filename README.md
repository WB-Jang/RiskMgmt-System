## cdc_user 생성

```
docker-compose exec oracle-db bash -c "sqlplus -s sys/your_password@//localhost:1521/XE as sysdba <<'SQL'
CREATE USER cdc_user IDENTIFIED BY cdc_pass;
GRANT CREATE SESSION, CREATE TABLE, CREATE VIEW TO cdc_user;
GRANT UNLIMITED TABLESPACE TO cdc_user;
COMMIT;
SQL"
```

## tex_table 생성 및 샘플 삽입(sys로 생성)
```
docker-compose exec oracle-db bash -c "sqlplus -s sys/your_password@//localhost:1521/XE as sysdba <<'SQL'
CREATE TABLE cdc_user.TRX_TABLE (
  tx_id NUMBER GENERATED BY DEFAULT ON NULL AS IDENTITY PRIMARY KEY,
  account_no VARCHAR2(30),
  amount NUMBER(12,2),
  created_at TIMESTAMP
);
INSERT INTO cdc_user.TRX_TABLE (account_no, amount, created_at) VALUES ('ACC123', 1000.50, SYSTIMESTAMP);
INSERT INTO cdc_user.TRX_TABLE (account_no, amount, created_at) VALUES ('ACC456', 250.00, SYSTIMESTAMP);
COMMIT;
SQL"
```

### (1) cdc_user로 조회 확인
```
docker-compose exec oracle-db bash -c "sqlplus -s cdc_user/cdc_pass@//localhost:1521/XE <<'SQL'
SET PAGESIZE 100
SELECT tx_id, account_no, amount, TO_CHAR(created_at,'YYYY-MM-DD HH24:MI:SS') FROM TRX_TABLE ORDER BY tx_id;
EXIT;
SQL"
```

### (2) python으로 조회 확인(터미널에서 즉시 수행 가능)
```
pip install oracledb
python - <<'PY'
import oracledb
conn = oracledb.connect(user='cdc_user', password='cdc_pass', dsn='localhost:1521/XE')
cur = conn.cursor()
cur.execute('SELECT tx_id, account_no, amount, created_at FROM TRX_TABLE ORDER BY tx_id')
for r in cur:
    print(r)
cur.close(); conn.close()
PY
```
